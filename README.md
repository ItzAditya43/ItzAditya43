## 🔩 Built from scratch

- **A language model.** BPE tokenizer, RoPE/GQA transformer, training loop and KV-cache inference, trained end to end on a single 4GB GPU. → [Zenith-AI](https://github.com/ItzAditya43/Zenith-AI)
- **A network bypass layer.** Per-app WireGuard tunneling, system-wide encrypted DNS and TLS-record fragmentation against SNI-based filtering, in Rust. → [Detour](https://github.com/ItzAditya43/Detour)
- **A coding agent on local models.** Chat, agentic coding, deep research, long-term memory, image gen and voice, all on Ollama with nothing leaving the machine. → [Zenith](https://github.com/ItzAditya43/Zenith)
- **A privileged Linux control plane.** Processes, cgroups, systemd, Docker and GPU behind one desktop app. → [Trace](https://github.com/ItzAditya43/Trace)
- **A world model that plans by imagining.** Learns dynamics with no reward signal, then picks actions with random-shooting MPC. → [Neural World Model](https://github.com/ItzAditya43/Neural_World_Model)
